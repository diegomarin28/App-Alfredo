# Mockup de referencia

Copia de las pantallas diseñadas en el canvas (https://claude.ai/artifact/SB7ptcbNAU93KnzPF4TGxT),
que no se puede abrir desde otras cuentas. Cada `.dc.html` es una pantalla de 390×844
(formato Design Component: el markup y los estilos inline son la referencia de layout,
colores, tamaños y espaciados; el `<script>` solo maneja estados de demo).
